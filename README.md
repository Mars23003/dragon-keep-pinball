# 龍堡彈珠台 · Dragon Keep Pinball

手機直向優先的奇幻 3D 彈珠台。由 Three.js / WebGL 2 渲染程序化城堡、巨龍、水晶、架高軌道與擋板，透過固定步長碰撞物理控制銀球。

## 開始遊玩

1. 按「進入城堡」。
2. 長按中央按鈕蓄力，放開發射。約 63–84% 力道可取得技巧發射。
3. 左右拇指操作擋板，可同時按住。電腦可使用 A / D、左右方向鍵與空白鍵；P 或 Escape 暫停。
4. 每局 3 球。發射後有 9 秒護球，三球模式開始有 12 秒護球。

## 任務與計分

擊中左右盾牌 → 開啟城門 → 完成左右天空橋與中央城門 → 喚醒巨龍 → 依序完成左軌道、右軌道與城門 → 開啟寶庫 → 鎖入 3 球 → 三球模式。

| 項目 | 基礎得分 |
| --- | ---: |
| 魔法水晶 | 100 |
| 紫色符文 | 250 |
| 城門盾牌 | 350 |
| 城堡入口 | 800 |
| 天空橋 | 1,000 |
| 天空橋連擊 | 每段額外 500，上限額外 3,000 |
| 技巧發射 | 2,000 |
| 龍的考驗每段 | 2,000 |
| 寶珠鎖定 | 1,000 |
| 三球模式城門大獎 | 5,000 |

得分乘以目前倍率。集齊 3 枚符文增加倍率，上限 ×6；8 秒內再次完成軌道可延續連擊。龍的考驗初始 35 秒，完成前兩段各增加 8 秒；逾時可再次射入城門重試。落球時結算本球累積獎勵。三球減少至一球時回到一般模式，不扣本局球數。

個人最高分與音效偏好保存在目前瀏覽器的 localStorage，未提供線上排行榜。切到其他分頁或失去焦點會自動暫停。儲存功能不可用時仍可遊玩。

## 本機執行

直接開啟 `index.html` 會受到 ES module 本機檔案限制，請使用 HTTP 伺服器：

```sh
python3 -m http.server 8080
```

開啟 `http://localhost:8080`。靜態檔案皆使用相對路徑，適用 GitHub Pages 的 repo 子路徑，無需建置、API key 或後端。

## GitHub Pages

建立 `dragon-keep-pinball` repo，將本目錄內容提交到 `main`。前往 **Settings → Pages → Source → GitHub Actions**，使用 `.github/workflows/pages.yml` 自動測試並部署。

也可使用 **Deploy from a branch → main → / (root)**；網站入口在根目錄，`.nojekyll` 已包含。

## 驗證

```sh
npm test
```

8 項獨立規則測試涵蓋發射、碰撞、擋板能量、完整任務流程、護球與落球、暫停、倍率、軌道回球與長時間座標穩定性。

另有 Playwright 瀏覽器驗證：啟動本機伺服器後，安裝測試用 Playwright 與 Chromium，執行 `node tests/browser-check.cjs`。自訂 Chromium 可用 `PINBALL_CHROMIUM_PATH` 指定。測試會驗證 WebGL、雙指操作、取消觸控、暫停、說明返回、5 種畫面尺寸、結束畫面及最高分保留；截圖輸出到專案目錄的上一層。可於本機網址加 `?debug=1` 取得測試用引擎狀態。

## 架構

- `physics.js`：固定 1/180 秒步長；球台平面碰撞、旋轉擋板與任務狀態。
- `table.js`：程序化 3D 模型、燈光、軌道、粒子及鏡頭。
- `game.js`：觸控、鍵盤、Web Audio、計分 UI 及儲存。
- 架高軌道使用指定 3D 路徑，不是完整剛體模擬。
